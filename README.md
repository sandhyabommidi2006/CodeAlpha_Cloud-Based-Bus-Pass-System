# 🚌 Cloud Bus Pass System

A Flask-based web application that allows users to apply for, manage, and track bus passes online. The system includes secure user authentication, automatic fare calculation, online payment simulation, and an admin panel for managing applications.

---

## 📌 Features

- User Registration
- User Login & Logout
- Apply for Bus Pass
- Automatic Fare Calculation Based on Distance
- Unique Bus Pass ID Generation
- Online Payment (Simulation)
- View Bus Pass Details
- Check Pass Status
- Delete Bus Pass


---

## 🗄 Database

The project uses **SQLite** with two tables:

### Users
- ID
- Full Name
- Email
- Password

### Bus Pass
- Pass ID
- User Email
- Source
- Destination
- Distance
- Amount
- Status

---

## 🔄 Workflow

1. Register
2. Login
3. Apply for Bus Pass
4. Enter Travel Details
5. Fare Calculated Automatically
6. Complete Payment
7. Bus Pass Generated
8. Admin Reviews Application
9. Admin Approves or Rejects
10. User Checks Pass Status
