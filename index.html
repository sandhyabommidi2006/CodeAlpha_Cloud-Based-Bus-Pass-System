Cloud-Based Bus Pass System

Welcome to the Cloud-Based Bus Pass Management System. This application allows users to apply for bus passes online, prevents incorrect fare calculation through automatic pricing, and generates unique pass IDs to reduce ticket duplication and theft.

Features

  • Online Bus Pass Application
  • Automatic Fare Calculation
  • Unique Pass ID Generation
  • Secure Login System
  • View Pass Status
  • Cloud Deployment Ready
  • Admin Approval System
